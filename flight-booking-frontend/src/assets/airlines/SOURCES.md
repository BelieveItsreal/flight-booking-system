# Airline logo sources

The three Wikimedia Commons logos are marked **public domain** there (too simple for copyright), and the
Simple Icons icon is **CC0**. All four are still **trademarks** of their airlines: fine for this practice
project; get permission before using them in a real, public product.

| File | Taken from | What was kept |
|---|---|---|
| `indigo.svg` | [Simple Icons `indigo`](https://simpleicons.org/?q=indigo) (simple-icons@16.36.0, CC0) | The dotted aircraft, in white on IndiGo blue `#09009B`, like IndiGo's own site icon |
| `air-india.svg` | [Air India logo (2007–2023).svg](https://commons.wikimedia.org/wiki/File:Air_India_logo_(2007%E2%80%932023).svg) | The red/orange bird (first two paths); the "AIR INDIA" text removed |
| `vistara.svg` | [Vistara Logo.svg](https://commons.wikimedia.org/wiki/File:Vistara_Logo.svg) | The gold star emblem (`path1`); the "vistara" text removed |
| `spicejet.png` | [New SpiceJet Logo.png](https://commons.wikimedia.org/wiki/File:New_SpiceJet_Logo.png) | The orange dots (78×78 px crop); the "SpiceJet" text removed |
